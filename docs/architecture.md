# 架构设计

## 设计目标

ScopeLatch 将不受约束的仓库任务转化为有边界、有证据的执行生命周期。它不替代测试、代码审查、CI 或操作系统隔离，而是负责把这些能力编排成可验证的工程闭环。

## 控制流程

1. `task.mjs` 从任务中提取意图、文件指向、业务域和风险信号。
2. `indexer.mjs` 与 `source-authority.mjs` 识别仓库文件、测试、导入关系和权威源码根。
3. `context-builder.mjs` 对正式源码、参考资料、历史副本、重复内容和生成文件进行排序。
4. `impact-analyzer.mjs` 从任务中的精确文件路径构建 `writeTargets`，并另行计算只读的直接目标、反向依赖、风险信号和跨模块同步要求。
5. `validation-planner.mjs` 根据影响面和 L1-L4 风险生成可执行验证图。
6. `session-binding.mjs` 将写入租约绑定到任务、会话、分支、提交、有效期、基线和精确写入目标。
7. Codex Hook 在工具执行前检查授权，在执行后核对副作用，并在停止时自动触发完整收尾；失败时继续阻止停止。
8. `guard.mjs` 将实际工作区变化与计划比较，并检查受保护边界。
9. `safe-executor.mjs` 通过结构化命令契约执行验证，限制网络、环境、资源、输出和可写目录，不使用 `shell: true`。
10. `validator.mjs` 将闭合 V4 outcome 和内容摘要写入证据索引。
11. `closeout.mjs` 依次执行 Guard、验证、第二次 Guard、报告、指标和失败知识处理。
12. 独立 Auditor 从候选树、策略、工具链和证据索引重算结论；运行器不能给自己签发正式证明。
13. `repair.mjs` 在配置允许的轮数内执行聚焦修复，避免无限返工。

## 信任边界

- **仓库配置：** 作为可信策略输入，变更时必须按代码审查。
- **任务与智能体输出：** 在完成范围约束和验证前均视为不可信。
- **工具命令：** 受 Hook 解析和策略限制，但并未获得物理隔离。
- **Git 工作区：** 是 Guard 的主要证据来源；仓库外副作用需要其它监控手段。
- **外部服务：** 凭据和原始载荷不得进入被跟踪的报告或上下文包。
- **Docker 沙箱：** 提供可选的更强进程隔离，但不替代宿主机加固。
- **候选与 Judge：** CI 中候选代码只是被评估对象；受保护基线提供 Judge、策略和 Auditor。
- **Formal Attestation：** 只有独立 Auditor 可以签发，并且必须绑定精确提交、树、策略和工具链。

## 状态模型

公开且需要版本控制的策略位于 `.harness/*.json`、`.codex/` 和项目规则中。运行生成的 `runs`、`state`、`cache`、`security`、失败日志和候选规则必须保持忽略。

V4 运行清单使用 schema 6，过程状态与判定 outcome 分离。过程状态描述计划、执行和收尾生命周期；判定只能使用闭合集合 `PASS`、`FAIL`、`BLOCKED`、`ERROR`、`CANCELED` 和 `NOT_APPLICABLE`。活动会话绑定的运行未完成前，Hook 会拒绝提交。读取上下文不会授权写入。

V3 运行时、状态升级和兼容适配器已移除。历史 V3 文件只允许作为人工审计历史存在，不得成为当前运行输入、回退判定或正式证据。

## H0–H9 信任分层

- **H0–H2：** 冻结信任契约、失败关闭语义和内容寻址证据链。
- **H3–H5：** 绑定 Git 候选身份、可执行不变量目录和独立 Auditor。
- **H6–H7：** 保证并发状态原子性，并使用安全执行器约束命令副作用。
- **H8：** 在 Windows GitHub Actions 中运行非权威 Shadow 观察，要求冷/缓存可复现和完整业务 Profile。
- **H9：** 只有外部强制策略、H8 资格窗口和正式工作流均被观测后才允许激活。

本地实现通过不等于正式资格。H8/H9 缺少外部证据时必须保持 `BLOCKED`。

## 扩展方式

ScopeLatch 采用配置优先的接入方式：

- 声明权威源码与就绪标记；
- 配置正式、参考、历史和生成文件路径；
- 配置风险模式和禁止写入目录；
- 为项目提供明确的验证能力；
- 维护经过人工审查的项目规则。

内置任务词汇和同步域覆盖 Web、API、前端、存储、鉴权、支付、模型运行时和叙事系统。其它项目可以扩展现有模块，或在未来接入独立领域包。
